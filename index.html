Hasse Diagram Guide

Everything you need to know before entering the journey.

01

What is a Hasse Diagram?

A Hasse diagram is a visual representation of a partially ordered set (poset). Elements are represented as nodes and their ordering relationships are shown using lines.

  • Elements are represented by nodes.
  • Smaller elements are placed below larger elements.
  • Only important ordering relationships are shown.
  • Arrowheads are not used.
02

What is a Poset?

A partially ordered set is a set together with a relation satisfying three important properties.

Reflexive a ≤ a
Antisymmetric a ≤ b and b ≤ a → a = b
Transitive a ≤ b and b ≤ c → a ≤ c
03

From Relation to Hasse Diagram

1 Write the elements.
2 Remove self-pairs like (a,a).
3 Remove arrowheads.
4 Find directly related elements.
5 Remove transitive relationships.
6 Draw the remaining connections.
04

Cover Relations

If a < b and there is no element between them, then b covers a.

b
a

Here b covers a and c covers b. There is no direct connection between a and c.

05

Transitive Relations

If a < b and b < c, then a < c.

However, the transitive relationship is not drawn directly in a Hasse diagram.

a b c
⚠ Do not add the direct edge a — c.
06

Divisibility

Hasse diagrams can also represent divisibility relationships.

A = {1, 2, 3, 6}

1 divides 2 and 3, while 2 and 3 divide 6. The relation 1 → 6 is transitive, so it is removed.

2 3
1
07

Position of Elements

Elements should be arranged according to their ordering. Smaller elements are generally placed below larger ones.

The exact horizontal position can change, but the vertical order must remain correct.

Higher / Larger
↓
Lower / Smaller
08

What Should NOT Be Drawn?

✕ Self-loops such as (a,a)
✕ Arrowheads
✕ Transitive edges
✕ Unrelated connections

A Hasse diagram should contain only the necessary cover relations.

09

Quick Rule to Remember

REMOVE Self-pairs
→
ARRANGE Smaller below larger
→
CONNECT Cover relations
→
CHECK No transitive edges
